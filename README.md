# Career DNA Analyzer 🤖

Career DNA Analyzer is an AI-powered career guidance platform designed to help students understand their skills, interests, and career potential.

The system uses a career assessment consisting of multiple questions and analyzes the student's responses to calculate career-wise scores. Based on the assessment results, it recommends a suitable career path and provides an overall score and industry-readiness level.

## Key Features

- Student registration and login
- Career assessment with multiple-choice questions
- Automatic evaluation of student responses
- Career-wise scoring system
- Personalized career recommendation
- Overall career score
- Industry-readiness score
- Career result dashboard
- AI-powered career chat assistant
- Admin panel for managing career questions
- Student assessment and result management

## Technology Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- REST APIs

## Main Modules

### Student Module
Students can:
- Login to the system
- Take the career assessment
- Submit answers
- View their Career DNA results
- Interact with the Career AI chatbot

### Admin Module
Admins can:
- Login to the admin panel
- Add career assessment questions
- Manage assessment questions
- View student results

### Career DNA Engine
The system analyzes assessment responses and calculates:
- Recommended Career
- Overall Score
- Industry Readiness
- Career-wise Scores

## Purpose

The main goal of Career DNA Analyzer is to help students identify suitable career directions based on their abilities and assessment responses rather than relying only on general career suggestions.
